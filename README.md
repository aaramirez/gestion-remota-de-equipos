# Gestión remota de equipos (ACS)

Cómo un operador configura, actualiza y diagnostica a distancia los equipos que tiene en casa de sus clientes: TR-069 y TR-369 a fondo, el modelo de datos TR-181, el aprovisionamiento sin visita, los cambios masivos, el firmware, los diagnósticos, la seguridad y la escala de un ACS.

**Ver en línea:** https://aaramirez.github.io/gestion-remota-de-equipos/
